# Архитектура приложения VK Desktop

## Обзор

VK Desktop построено на модульной архитектуре с четким разделением ответственности. Каждый модуль отвечает за свою область функциональности и может быть разработан и тестирован независимо.

## Общая структура

```
┌──────────────────────────────────────────────────────┐
│              Главное приложение (main.py)            │
│  - Инициализация всех компонентов                   │
│  - Управление жизненным циклом                      │
│  - Координация между модулями                       │
└───────────────────────┬───────────────────────��────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
        ▼               ▼               ▼
   ┌────────┐     ┌────────┐     ┌────────┐
   │  API   │     │  UI    │     │ AUDIO  │
   │ Module │     │ Module │     │ Module │
   └────────┘     └────────┘     └────────┘
        │               │               │
        ▼               ▼               ▼
   ┌────────┐     ┌────────┐     ┌────────┐
   │ VK API │     │ wxPython│    │  VLC   │
   │ Client │     │ Widgets │    │ Player │
   └────────┘     └────────┘     └────────┘
```

## Модули

### 1. API модуль (src/api/)

Отвечает за взаимодействие с VK API и управление данными.

**Основные файлы:**
- `vk_client.py` - основной VK API клиент
- `methods.py` - методы для различных операций
- `models.py` - модели данных (Message, User, Group и т.д.)
- `exceptions.py` - пользовательские исключения

**Основные функции:**
- Получение сообщений
- Отправка сообщений
- Управление друзьями
- Получение информации профиля
- Получение новостной ленты
- Поиск пользователей и групп
- Получение аудиозаписей

**Архитектура:**
```python
class VKClient:
    """Основной клиент VK API"""
    - auth()              # Аутентификация
    - get_messages()      # Получить сообщения
    - send_message()      # Отправить сообщение
    - get_friends()       # Получить друзей
    - get_profile()       # Получить профиль
    - search_users()      # Поиск пользователей
```

### 2. UI модуль (src/ui/)

Отвечает за графический интерфейс приложения на wxPython.

**Основные файлы:**
- `main_frame.py` - главное окно приложения
- `widgets.py` - пользовательские виджеты
- `dialogs.py` - диалоговые окна
- `panels.py` - панели и страницы
- `styles.py` - стили и темы

**Основные компоненты:**
- Главное окно (Main Frame)
  - Меню
  - Боковая панель навигации
  - Основная область содержимого
  - Строка состояния

- Панель сообщений (Messages Panel)
  - Список контактов
  - Область чата
  - Поле ввода сообщения
  - Кнопки управления

- Панель профиля (Profile Panel)
  - Информация профиля
  - Статус
  - Аватар
  - Кнопки действий

- Панель аудио (Audio Panel)
  - Плеер управления
  - Плейлист
  - Поиск треков
  - Информация о треке

**Архитектура:**
```python
class MainFrame(wx.Frame):
    """Главное окно приложения"""
    - init_ui()           # Инициализация интерфейса
    - create_menu()       # Создание меню
    - create_panels()     # Создание панелей
    - bind_events()       # Привязка событий

class MessagesPanel(wx.Panel):
    """Панель сообщений"""
    - load_contacts()     # Загрузить контакты
    - load_messages()     # Загрузить сообщения
    - send_message()      # Отправить сообщение
    - on_message_received()  # Обработчик получения сообщения
```

### 3. Audio модуль (src/audio/)

Отвечает за звуковые события и уведомления.

**Основные файлы:**
- `sound_events.py` - определение типов событий
- `sound_manager.py` - менеджер звуков
- `sound_config.py` - управление конфигурацией

**Основные функции:**
- Воспроизведение звуков для различных событий
- Управление громкостью
- Кэширование звуков
- Асинхронное воспроизведение
- Приоритизация событий

**См. документацию:** [AUDIO_SYSTEM.md](AUDIO_SYSTEM.md)

### 4. Media модуль (src/media/)

Отвечает за воспроизведение музыки и управление плейлистами.

**Основные файлы:**
- `vlc_player.py` - VLC плеер
- `playlist.py` - управление плейлисто��
- `audio_fetcher.py` - загрузка аудиозаписей из VK

**Основные функции:**
- Поиск и загрузка музыки
- Воспроизведение треков
- Управление плейлистом
- Контроль громкости
- Информация о текущем треке

### 5. Auth модуль (src/auth/)

Отвечает за аутентификацию и управление токенами.

**Основные файлы:**
- `auth_manager.py` - менеджер аутентификации
- `token_storage.py` - хранение токенов
- `oauth_handler.py` - обработка OAuth

**Основные функции:**
- Получение токена доступа
- Сохранение и восстановление токена
- Проверка срока действия токена
- Управление сессией пользователя

### 6. Utils модуль (src/utils/)

Вспомогательные функции и утилиты.

**Основные файлы:**
- `logger.py` - настройка логирования
- `config.py` - работа с конфигурационными файлами
- `helpers.py` - вспомогательные функции
- `constants.py` - константы приложения

## Взаимодействие модулей

### Получение сообщения

```
API Module
    │
    ├─→ Запрос к VK API
    ├─→ Парсинг ответа
    └─→ Передача данных
         │
         ▼
    UI Module
         │
         ├─→ Обновление списка сообщений
         ├─→ Отображение в чате
         └─→ Отправка события
              │
              ▼
         Audio Module
              │
              ├─→ Определение типа события
              ├─→ Выбор звука
              └─→ Воспроизведение
```

### Отправка сообщения

```
UI Module
    │
    └─→ Пользователь вводит текст и нажимает "Отправить"
         │
         ▼
    Audio Module
         │
         └─→ Воспроизведение звука действия
              │
              ▼
         API Module
              │
              ├─→ Отправка сообщения через VK API
              ├─→ Получени�� ответа
              └─→ Обновление UI
                   │
                   ▼
              Audio Module
                   │
                   └─→ Воспроизведение звука успеха/ошибки
```

## Жизненный цикл приложения

### Запуск

```
1. Инициализация логирования (utils/logger.py)
2. Загрузка конфигурации (utils/config.py)
3. Инициализация аутентификации (auth/auth_manager.py)
4. Проверка токена доступа
5. Инициализация Audio Module (audio/sound_manager.py)
6. Инициализация Media Module (media/vlc_player.py)
7. Инициализация API Module (api/vk_client.py)
8. Создание главного окна (ui/main_frame.py)
9. Запуск основного цикла (wx.App.MainLoop())
```

### Завершение

```
1. Закрытие главного окна
2. Остановка всех потоков
3. Завершение воспроизведения звуков (audio/sound_manager.shutdown())
4. Остановка VLC плеера (media/vlc_player.stop())
5. Сохранение конфигурации (utils/config.py)
6. Закрытие соединения с API
7. Завершение приложения
```

## Потоки выполнения

### Главный поток (Main Thread)
- wxPython главный цикл (UI)
- Обработка событий пользователя
- Обновление интерфейса

### Фоновый поток (Background Thread)
- Загрузка данных из API
- Запрос к VK API
- Обновление кэша

### Поток воспроизведения (Playback Thread)
- Воспроизведение звуков
- Управление очередью событий
- Работа с VLC

### Поток мониторинга (Monitor Thread)
- Проверка новых сообщений
- Обновление статусов
- Уведомления

## Производительность

### Оптимизации

1. **Кэширование звуков** - загруженные звуки хранятся в памяти
2. **Асинхронная загрузка** - данные загружаются в фоновом потоке
3. **Очередь событий** - события обрабатываются по приоритету
4. **Ленивая инициализация** - компоненты создаются при необходимости

### Профилирование

```bash
# Профилирование производительности
python -m cProfile -s cumtime main.py

# Анализ использования памяти
python -m memory_profiler main.py
```

## Расширяемость

Архитектура позволяет легко добавлять новые функции:

### Добавление новой команды API

```python
# В api/methods.py
class VKMethods:
    def get_user_photos(self, user_id: int):
        """Получить фото пользователя."""
        # Реализация
        pass
```

### Добавление новой UI панели

```python
# В ui/panels.py
class PhotosPanel(wx.Panel):
    """Панель просмотра фотографий."""
    def __init__(self, parent):
        super().__init__(parent)
        self.init_ui()
```

### Добавление нового типа события

```python
# В audio/sound_events.py
class AudioEvent(Enum):
    PHOTO_RECEIVED = "photo_received"
```
