# VK Desktop - Неофициальное приложение ВКонтакте для Windows

## Описание

**VK Desktop** — это полнофункциональное десктопное приложение для ВКонтакте, разработанное на Python с использованием wxPython. Приложение полностью адаптировано для работы со скрин-ридерами (NVDA, JAWS) и предоставляет доступ ко всем основным функциям социальной сети.

## Основные возможности

- 📱 Просмотр новостной ленты
- 💬 Отправка и получение личных сообщений
- 👥 Управление друзьями и подписками
- 🎵 Встроенный музыкальный плеер (VLC)
- 📞 Просмотр стены и профилей
- 🔔 Уведомления в реальном времени
- ♿ Полная поддержка экранных дикторов (NVDA, JAWS)
- 🎨 Удобный интерфейс на wxPython

## Системные требования

- Windows 7/10/11
- Python 3.8+
- VLC Media Player (портабельная или установленная версия)
- Экранный диктор для доступных функций (NVDA, JAWS или встроенный Narrator)

## Установка

### Зависимости

```bash
pip install -r requirements.txt
```

### Настройка VLC

Приложение автоматически ищет VLC в следующем порядке:
1. Портабельная версия VLC в папке `./vlc/`
2. Установленная версия VLC в стандартных путях Windows
